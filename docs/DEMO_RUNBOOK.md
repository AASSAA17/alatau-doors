# Показ Alatau Doors

Это неофициальная демонстрация. Каталог, цены, аккаунты и обращения вымышлены. AI-интерьеры не являются выполненными заказами. WhatsApp доступен только как предпросмотр и копирование текста.

## Подготовка

Node.js 24, зависимости из package-lock.json. На новом компьютере сначала `npm ci`. На текущем Windows при необходимости:

```powershell
$env:PATH = "$env:USERPROFILE\.local\node\node-v24.22.1-win-x64;$env:PATH"
npm.cmd run presentation:setup
npm.cmd run build
npm.cmd run presentation:start
```

Открыть `http://127.0.0.1:3200/ru` или `/kk`. Для разработки — `npm run presentation:dev`. Порт 3200 должен быть свободен. Остановка — Ctrl+C. Секрет, путь БД и origin задаёт `scripts/presentation.mjs`; менять основной `.env.local` не требуется.

- Основная база: `.local/alatau-demo.sqlite`, обычный dev на 3000.
- Презентация: `.local/presentation-demo.sqlite`, набор visual-v1 — 12 моделей, 5 аккаунтов и 5 стартовых заявок. Setup повторяемый, существующие записи не сбрасывает.
- Регрессия: отдельная `.local/e2e-<run>-demo.sqlite`, сервер 3100. Технические записи тестов не переносятся в презентацию.

`npm run presentation:accounts` показывает доступы **только в локальном терминале**. Не включайте терминал с паролями в запись экрана. Зашифрованная памятка `.local/presentation-credentials.json` читается существующим механизмом с отдельным секретом `.local/presentation-config.json`. Оба файла остаются локальными. Пароли и сессии в документацию не копируются.

Для покупателя, администратора и продавца используйте отдельные профили браузера или изолированные окна. Вкладки одного профиля разделяют сессию.

## Последовательность показа

1. **Каталог** `/ru/catalog`: найти Line 01, показать цену за полотно, фильтр и сортировку. Переключить RU/ҚАЗ — текущая страница и параметры сохраняются.
2. **Подобрать двери** `/ru/door-finder`: межкомнатная → 2 двери → 90 000 ₸ за полотно. Результат Line 01. Вернуться назад и показать сохранённые ответы. Для пустого результата временно указать 1 000 ₸, затем вернуть бюджет.
3. Выбрать настоящий размер 900 × 2100 и добавить модель в **Мою подборку** `/ru/selection`. Включить короб и фурнитуру. При исходном прайсе предварительная сумма — 238 000 ₸. Если администратор уже менял прайс, сумма будет другой.
4. **WhatsApp-предпросмотр**: показать модели, размеры, количество, комплектацию и статус суммы. Нажать «Скопировать текст». Никакой чат не открывается, заявка не создаётся. При запрете буфера текст доступен для ручного копирования.
5. Войти покупателем через кнопку подборки. После входа вернуться в неё автоматически. Нажать «Добавить гостевые позиции в эту подборку»: позиции объединяются с сохранённым черновиком, сервер сохраняет результат, после успеха локальная гостевая копия убирается. При превышении лимита 20 единиц/30 строк появляется ошибка; ничего молча не обрезается. Проверить состав и создать заявку.
6. В отдельном профиле войти администратором. В `/ru/admin` открыть созданную заявку и назначить продавца. Не менять роли существующих участников во время основного показа.
7. В профиле назначенного продавца открыть `/ru/seller`. Он видит только назначенные ему заявки. Полоса сверху объясняет этапы, не фильтрует список. Открыть заявку, уточнить состав, сохранить, добавить внутренний комментарий и подготовить расчёт.
8. Обновить заявку у покупателя. Показать итог, состав сохранённой версии и публичную историю. Внутренний комментарий покупателю недоступен. Новая версия расчёта не переписывает предыдущую.
9. Показать `/ru/about` и `/ru/projects` через футер: содержательная информация о демонстрации и «Идеи для интерьера» с AI-маркировкой. Это не подтверждённая история магазина или портфолио.

## Что изменяет данные

- Просмотр, фильтры, ответы мастера в URL, информационные страницы и копирование сообщения не создают записи заявок.
- Гостевые подборка/избранное хранятся в браузере. Авторизация создаёт сессию; регистрация — аккаунт BUYER.
- Добавление модели авторизованным покупателем и импорт гостевых позиций меняют его черновик в БД.
- Создание заявки, назначение, редактирование состава, расчёт, статус и комментарии меняют презентационную БД. Настройки и прайс администратора также сохраняются.
- Изменение текущего прайса не меняет опубликованные расчёты. Изменения не исчезают при перезапуске или повторном setup.

## Новый чистый набор для следующего показа

Если прежний набор уже изменён, сохраните его архивом. **Не удаляйте основную БД и не запускайте seed поверх неё.** Остановите презентационный сервер и закройте SQLite-инструменты, использующие презентационный файл. Следующий скрипт переносит только явно перечисленные файлы презентации; каталог архива создаётся новым. WAL/SHM сохраняются вместе с БД, если присутствуют.

```powershell
$demoRoot = (Resolve-Path '.local').Path
if (Get-NetTCPConnection -State Listen -LocalPort 3200 -ErrorAction SilentlyContinue) {
  throw 'Сначала остановите презентационный сервер на 3200'
}
$demoArchive = Join-Path $demoRoot ('presentation-archive-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
if (Test-Path -LiteralPath $demoArchive) { throw 'Архив уже существует' }
New-Item -ItemType Directory -Path $demoArchive | Out-Null
$demoFiles = @('presentation-demo.sqlite', 'presentation-demo.sqlite-wal',
  'presentation-demo.sqlite-shm', 'presentation-config.json', 'presentation-credentials.json')
foreach ($demoName in $demoFiles) {
  $demoSource = [IO.Path]::GetFullPath((Join-Path $demoRoot $demoName))
  $demoTarget = [IO.Path]::GetFullPath((Join-Path $demoArchive $demoName))
  if (-not $demoSource.StartsWith($demoRoot + '\') -or
      -not $demoTarget.StartsWith($demoArchive + '\')) { throw 'Недопустимый путь' }
  if (Test-Path -LiteralPath $demoSource) {
    Move-Item -LiteralPath $demoSource -Destination $demoTarget -ErrorAction Stop
  }
}
npm.cmd run presentation:setup
npm.cmd run presentation:start
```

Это ручная операция для организатора показа, она не выполняется приложением при старте. Архив содержит локальные конфиденциальные данные — не публикуйте его. Для возврата прежнего набора остановите сервер, сохраните текущий набор отдельным архивом и восстановите все файлы прежнего набора вместе, включая конфигурацию секрета; не смешивайте их. Основные `.local/alatau-demo.sqlite` и `.env.local` в этих операциях не участвуют.

## Проверки и снимки

```bash
npm run typecheck
npm run lint
npm run build
npx playwright install chromium firefox
npm run test:e2e
npm run presentation:capture-completion
```

Перед capture освободите 3200; команда сама запускает и останавливает production-сервер. Новые экраны сохраняются в `docs/screenshots/completion`, прежние 96 снимков не пересоздаются. Для предпросмотра используется изолированный гостевой контекст; capture не создаёт заявки и не меняет бизнес-данные презентации. Если количество записей уже не соответствует чистому fixture, capture останавливается без сброса.

Firefox smoke — автоматизированный браузер на Windows, не проверка реального iPhone. Точные результаты и ограничения последнего прогона — в `VERIFICATION.md`.

## Перед коммерческим запуском

Нужны подтверждённые ассортимент/состав/покрытие/цвет/фото/цены/контакты и условия услуг; редактура KK носителем; юридические сведения и политика данных. Нужны отдельная production-БД и секрет, HTTPS, безопасная выдача первого администратора, восстановление доступа, резервные копии с проверкой восстановления и мониторинг. SQLite требует постоянного диска и одного узла. Существующая защита запрещает реальный production с демобазой.

Внешняя отправка WhatsApp, оплата, email/SMS, склад, CMS портфолио и загрузка фото не реализованы и не входят в эту итерацию. Предварительная сумма не является подтверждённым коммерческим предложением.
