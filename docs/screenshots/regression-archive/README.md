# Архив предыдущей регрессии

Эти 11 снимков были получены в предыдущей итерации из изменяемого тестового набора. В нём сценарии создают Snapshot/UI model и UI workflow, редактируют профили. Это не презентационная версия и не доказательство загрязнения основной демобазы.

Проверка SQLite показала: основная alatau-demo.sqlite — 12 товаров, 5 аккаунтов и 5 заявок, без технических товаров. В прежних e2e-базах — 14–16 товаров, включая 2–4 технических, 9–11 пользователей и 15 заявок. Основные данные не удалялись.

Актуальные чистые экраны: [презентационный индекс](../presentation/README.md). Архив сохранён отдельно для прослеживаемости; не использовать эти снимки при показе клиенту.
