# Скриншоты Alatau Doors

- [Завершённые функции](completion/README.md): мастер, «О компании», интерьерные идеи, предпросмотр и локальные исправления. Новые снимки из той же отдельной презентационной базы.

- [Чистая презентация](presentation/README.md): отдельная база visual-v1, RU/KK, 360/390/768/1440 px, viewport и полная страница.
- [Архив предыдущей регрессии](regression-archive/README.md): исторические снимки с техническими данными тестов, не для показа клиенту.

Новые регрессионные артефакты остаются в игнорируемом `test-results`; они не копируются в презентационный каталог.
