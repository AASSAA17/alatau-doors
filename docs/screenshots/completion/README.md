# Презентационные экраны

Источник: отдельная presentation-demo.sqlite, набор visual-v1. Не используются e2e-базы.

Viewport-снимки сохранены 1:1 в CSS-пикселях (deviceScaleFactor=1), без масштабирования. Full — длинная страница. Для message-preview видимая область прокручена к тексту сообщения; остальные viewport-снимки показывают верх страницы. Здесь новые страницы и затронутые состояния; прежний комплект presentation не пересоздавался. Позиции для предпросмотра добавлены только в изолированный гостевой браузер, без изменения БД.
