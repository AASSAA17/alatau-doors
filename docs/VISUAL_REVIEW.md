# Визуальная проверка — Alatau Doors

Источник: изображение в сообщении пользователя, доступное и изученное в этой итерации. Локального `reference/ALATAU_DOORS_VISUAL_REFERENCE.png` нет. Сравнение выполнено визуально, без автоматического pixel diff исходного PNG.

| Область | Сопоставление с референсом и результат |
| --- | --- |
| Первый экран | Светлая композиция, фотография справа, крупный жирный uppercase-заголовок слева с зелёной последней строкой. Два реальных действия: каталог и сбор заявки. Нижняя полоса описывает доступные функции; вымышленные 1000 клиентов, 2 салона и гарантия не перенесены. |
| Типографика | Manrope/Inter сохранены; заголовки стали плотнее и выразительнее, цены и действия выделены. Фактические тексты длиннее макета из-за демонстрационных пояснений и работающих кабинетов. |
| Категории и модели | Уменьшены интервалы между секциями; две крупные категории, компактные карточки с границами, скруглением и избранным. На телефоне товары в две колонки. |
| Каталог | Desktop: фильтры слева, три колонки моделей, поиск/сортировка сверху. На планшете две колонки; на телефоне фильтры раскрываются. Только реальные свойства данных — тип и максимальный бюджет; декоративных цветов/стилей нет. В первом desktop viewport виден первый ряд с ценами за полотно. |
| Кадрирование | На карточках портреты с максимально полной дверью. Страница товара использует contain. Для горизонтального hero-ресурса положение кадра адаптировано отдельно. Четыре существующих AI-ресурса отличаются от картинок макета; полное совпадение дверей не заявляется. |
| Страница товара | Desktop: изображение, название/цена/размер/количество/добавление, отдельная панель характеристик. На телефоне последовательная колонка. Только существующие размеры и свойства; одна иллюстрация, без поддельных отзывов и миниатюр чужих моделей. |
| Кабинеты | В макете нет текущих ролевых кабинетов. До 900 px таблицы превращаются в карточки с подписями, моделью/размером/комплектацией/ценами и действиями. На 1440 px сохранены таблицы. RU/KK-меню раскрывается, длинные подписи переносятся; футер компактный. |
| Контакты | Пустые настройки показывают одно информационное сообщение. Адреса, карта и номера из макета не используются как сведения магазина. Заполненные администратором поля работают. |

PNG сохранены в исходном размере браузера. Длинные снимки помогают оценить секции и футер; viewport — реальный размер текста и элементов. Просмотр выявил тесную планшетную таблицу, после чего карточное представление расширено на 768 px и выполнены новый build, регрессия и захват.

Результат приближен по композиции, палитре, плотности карточек и иерархии действий. Это самостоятельный интерфейс на существующих данных и ресурсах. Логотип, изображения, состав навигации и функциональные тексты отличаются; точное воспроизведение макета не заявляется.
