# Визуальный референс

В этой итерации просмотрено изображение, приложенное пользователем непосредственно к сообщению: композиция главной, категории/модели, боковые фильтры каталога, товар и мобильные экраны.

Указанный в задании файл `docs/reference/ALATAU_DOORS_VISUAL_REFERENCE.png` при проверке отсутствовал. В каталоге текстового вложения также был только `Pasted text.txt`. Поэтому исходный PNG здесь не создавался заново и не заменялся похожим изображением. Источник визуального сравнения — доступное изображение в сообщении пользователя.

Макет используется для композиции и стиля. Отзывы, число клиентов/салонов, гарантии, адреса, телефоны, сроки, цены и характеристики из него не перенесены как факты магазина.
